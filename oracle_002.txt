DDL 정의어
정의 
데이터를 틀, 구조, 형식 자체를 생성, 변경, 삭제하는 언어
명령어 
CREATE, 새로운 테이블이나 데이터베이스를 만든다
ALTER, 기존의 테이블의 컬럼추가, 데이터 타입 변경 등을 변경
DROP, 테이블이나 데이터베이스를 통째로 삭제한다
TRUNCATE, 테이블 구조는 남기고 안의 데이터만 비워낸다

새로운 기능이나 서비스를 출시할 때 사용한다
상황 : 새로운 쇼핑 앱에 '상품 리뷰' 기능을 넣으려고 할 때 리뷰를 저장하기 위해서
리뷰작성자ID, 리뷰내용, 별점, 작성일자를 저장할 공간을 데이터베이스에 명령을해
새로운 구조를 만든다
 
DML 조작어
정의
구축된 테이블 구조에 실제 데이터를 입력, 수정, 삭제 하는 언어이다
명령어
INSERT 새로운 데이터를 등록한다
UPDATE 이미 존재하는 데이터를 수정
DELETE 특정 조건에 맞는 데이터를 선택해 삭제 
사용자가 앱이나 웹사이트에서 누르는 액션을 할때 프로그램에 의해 자동으로 실행

DQL 질의어 
정의 
데이터베이스에 저장되어 있는 데이터를 검색하고 조회하는 언어
명령어
SELECT 원하는 테이블에서 조건에 맞는 데이터를 조회해 화면에 뿌린다
사용자가 화면에서 정보를 보거나, 관리자가 데이터를 뽑아낼 때 실시간으로 계속 실행된다
