- HTML, CSS, JS 각각의 개념과 역할
- Flex 와 Grid 차이점

html 
웹문서 구조 의미를 정하는 마크업언어
마크업인 태그를 통해 화면에 구조화된 문서를 그릴수있다
css
html문서에 시각적표현을 입히는언어
인라인스타일, 내부스타일, 외부스타일 로 적용하고 선택자를 통해 html요소에 스타일을 적용할지 정할수있음

javascript
웹브라우저에서 사용되는 인터프리터 방식의 객체 지향 프로그램이 언어 
돔트리를 구성하고, 돔구조에 디자인과 스타일을 적용해 이벤트 발생시 실행될 동작을 정의
dom을 동적으로 조작하고 변경

flex와 grid의 차이점
flex는 가로나 세로로 줄을 세우는 1차원 레이아웃이고
grid는 가로와 세로를 동시에 사용해 표처럼 칸을 나누는 2차원 레이아웃이다
