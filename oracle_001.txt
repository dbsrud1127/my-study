관계형 데이터베이스(RDB)와 NoSQL 의 개념 및 차이점
관계형 데이터 베이스개념
모든 데이터를 테이블(표) 형태로 저장하고 데이블 간 관계를 통해
데이터의 연결성과 정합성을 유지하는 데이터베이스

NoSQL개념
고정된 테이블 구조 없이 유연한 형식으로 데이터 저장
대용량 데이터 처리와 수평 확장에 강하고 빠르게 변하는 데이터 구조에 적절하다
속도, 유연성, 확장성을 최우선으로 고려한다

차이점
관계형데이터 베이스와 NoSQL 의 
데이터구조와 스키마, 확장방식에  차이점이있다.
데이터 구조에서 관계형 데이터 베이스는 행과 열이 있는 테이블을 사용하고,
NoSQL은 문서, 키- 값 그래프 등을 사용한다.
관계형 데이터베이스는 고정스키마가 필수이고, NoSQL은 유연하거나 스키마가없다.
관계형DB는 수직확장이고 NoSQL은 수평확장이다.
