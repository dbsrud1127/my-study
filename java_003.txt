DDL 정의어
정의 
데이터를 틀, 구조, 형식 자체를 생성, 변경, 삭제하는 언어
명령어 
CREATE, 새로운 테이블이나 데이터베이스를 만든다
ALTER, 기존의 테이블의 컬럼추가, 데이터 타입 변경 등을 변경
DROP, 테이블이나 데이터베이스를 통째로 삭제한다
TRUNCATE, 테이블 구조는 남기고 안의 데이터만 비워낸다

새로운 기능이나 서비스를 출시할 때 사용한다
상황 : 새로운 쇼핑 앱에 '상품 리뷰' 기능을 넣으려고 할 때 리뷰를 저장하기 위해서
리뷰작성자ID, 리뷰내용, 별점, 작성일자를 저장할 공간을 데이터베이스에 명령을해
새로운 구조를 만든다
 
DML 조작어
정의
구축된 테이블 구조에 실제 데이터를 입력, 수정, 삭제 하는 언어이다
명령어
INSERT 새로운 데이터를 등록한다
UPDATE 이미 존재하는 데이터를 수정
DELETE 특정 조건에 맞는 데이터를 선택해 삭제 
사용자가 앱이나 웹사이트에서 누르는 액션을 할때 프로그램에 의해 자동으로 실행

DQL 질의어 
정의 
데이터베이스에 저장되어 있는 데이터를 검색하고 조회하는 언어
명령어
SELECT 원하는 테이블에서 조건에 맞는 데이터를 조회해 화면에 뿌린다
사용자가 화면에서 정보를 보거나, 관리자가 데이터를 뽑아낼 때 실시간으로 계속 실행된다

7/10 과제 관계형 데이터베이스(RDB)와 NoSQL 의 개념 및 차이점

관계형 데이터베이스(RDB)와 NoSQL 의 개념 및 차이점
관계형 데이터 베이스개념
모든 데이터를 테이블(표) 형태로 저장하고 데이블 간 관계를 통해
데이터의 연결성과 정합성을 유지하는 데이터베이스

NoSQL개념
고정된 테이블 구조 없이 유연한 형식으로 데이터 저장
대용량 데이터 처리와 수평 확장에 강하고 빠르게 변하는 데이터 구조에 적절하다
속도, 유연성, 확장성을 최우선으로 고려한다

차이점
관계형데이터 베이스와 NoSQL 의 
데이터구조와 스키마, 확장방식에  차이점이있다.
데이터 구조에서 관계형 데이터 베이스는 행과 열이 있는 테이블을 사용하고,
NoSQL은 문서, 키- 값 그래프 등을 사용한다.
관계형 데이터베이스는 고정스키마가 필수이고, NoSQL은 유연하거나 스키마가없다.
관계형DB는 수직확장이고 NoSQL은 수평확장이다.

상속
기존 클래스가 가지고있는 속성(필드)과 기능(메소드)을 새로운 클래스(자식)가 그대로 물려받는것
 
다형성
하나의 객체(참조변수)가 여러 가지 형태를 가질수있는 능력
부모타입의 참조변수로 자식 타입의 인스턴스를 참조할수있도록 다형성 구현


추상화
프로그램에 필요한 공통점을 추출하고 불필요한 특성은 제거하는 과정

캡슐화
객체의 데이터(필드)와 기능(메서드)을 하나의 클래스 안에 묶고, 외부에서 내부 
데이터를 접근하지 못하는것
